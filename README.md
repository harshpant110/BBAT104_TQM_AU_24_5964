# Restaurant Billing System — BBAT104 TQM

## Project Information

**Course:** BBAT104 — Fundamentals of TQM
**Academic Session:** 2026–27
**Project:** Restaurant Billing System
**Quality Goal:** Q03 — Improve Usability

## Project Objective

This project develops a Python-based Restaurant Billing System and applies Total Quality Management (TQM) principles to improve the usability of the baseline application.

The project will implement the five features assigned to Q03:

1. Dark Mode
2. Custom Themes
3. Dashboard Overview
4. Search Filters
5. Calendar

## Technology Stack

* Python 3.x
* Tkinter / CustomTkinter
* SQLite3
* Pandas
* Matplotlib / Seaborn
* Visual Studio Code
* GitHub

## Quality Improvement Approach

The project will apply TQM and Statistical Quality Control (SQC) techniques throughout development, including:

* CTQ
* SIPOC
* FMEA
* RPN
* Defect Logging
* Checksheets
* Pareto Analysis
* Fishbone Analysis
* PDCA

## Project Status

**Current Stage:** Project initialization

Development, testing, quality analysis, documentation, and final demonstration will be completed progressively throughout the project.
